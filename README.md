# 覚えKnight

忘却曲線をヒントに、学びを思い出すタイミングをつくる復習アプリ。
アイボリーと深緑を基調にした、レスポンシブなブラウザアプリです。

## 機能

- 学びの登録・編集・削除、カテゴリ別の検索
- 期限を迎えた学びの自動ポップアップ（常時有効・切り替え設定なし）
- 答えを隠して思い出す復習画面
- 覚え具合による次回タイミングの調整
- 復習スケジュールと復習回数の表示
- 任意のブラウザ通知

## ローカルで起動

ビルドやライブラリのインストールは不要です。Python 3を使用します。

```sh
git clone https://github.com/hgf81805/fukuyu.git
cd fukuyu
python3 -m http.server 4318 --bind 127.0.0.1 --directory dist
```

ブラウザで http://127.0.0.1:4318 を開きます。

JavaScriptの構文チェック（Node.jsが必要）:

```sh
node --check dist/app.js
```

## 復習のタイミング

初回は「1日後」「今すぐ」「3日後」から選択できます。
復習で「覚えていた」を選ぶと、前回からの間隔を1日・3日・7日・14日・30日の順で設定します。
30日のステップ以降は30日ごとです。「あいまい」は1日後、「もう一度」は10分後に設定します。
忘却曲線を参考にした目安で、個人に共通する最適間隔を保証するものではありません。

## データ・通知

- 復習内容と履歴はブラウザのlocalStorage（キー: `yohaku-data-v1`）に保存します。
- サーバーへのデータ送信や端末間同期はありません。
- オリジンやブラウザが変わると、データは共有されません。ブラウザデータの削除で消失します。
- ポップアップはアプリを開いて表示している間に動作します。期限を30秒間隔で確認し、再表示時にも確認します。
- アプリを閉じている間のバックグラウンド通知には対応していません。
- ブラウザ通知は対応環境で許可した場合に使用できます。
- フォントはGoogle Fontsを使用し、読み込めない場合はシステムフォントに切り替わります。

## 公開・Vercel

本番URL: https://oboe-kngiht.vercel.app

GitHubリポジトリ `hgf81805/fukuyu` の `master` ブランチでコードを管理します。
`vercel.json` に静的サイト設定を記載し、ビルドなしで `dist/` を配信します。
Vercelチーム: `hgf-51805` / プロジェクト: `oboe-kngiht`。

本番デプロイはVercel CLIで実行しています。

```sh
npx vercel@65.2.0 link --yes --scope hgf-51805 --project oboe-kngiht
npx vercel@65.2.0 deploy --prod --scope hgf-51805
```

GitHubへのpushによる自動デプロイは未接続です。
Vercel側でGitHubのLogin Connectionを追加してから、対象リポジトリをGit連携できます。

旧SitesのURLとVercelのURLは別のオリジンです。ブラウザに保存した復習データは自動移行されません。
localStorageキーは既存データの互換性のため `yohaku-data-v1` を維持しています。

## レスポンシブ対応

PCはサイドバー、タブレットはコンパクトなナビゲーション、スマホは下部ナビゲーションを使用します。
スマホのセーフエリアや横向き表示に対応し、フォームは入力時の拡大を避ける文字サイズにしています。
